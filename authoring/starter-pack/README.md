# __WORLD_NAME__

1. Add one approved `style-guide.png` beside this README, then add every source PNG named by `pack.json` to `assets/`.
2. Complete `pack.json` and `world.json` without changing engine code.
3. Run `npm run pack:validate -- <this-directory>`.
4. Run `npm run pack:install -- <this-directory>`.
5. Open `http://127.0.0.1:5173/?world=__WORLD_ID__&seed=12345&calibrate=1`.

See the repository's `docs/asset-pack-authoring.md` for scale, seams, animation, traffic, and composition rules.
