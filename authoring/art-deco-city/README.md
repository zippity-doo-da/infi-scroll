# Art Deco City

An original late-1920s city pack built from one approved master panorama. Every source asset follows the panorama's restrained hand-painted, television-distance design rules.

```bash
npm run pack:validate -- authoring/art-deco-city
npm run pack:install -- authoring/art-deco-city
```

Preview: `http://127.0.0.1:5173/?world=art-deco-city&seed=12345`
