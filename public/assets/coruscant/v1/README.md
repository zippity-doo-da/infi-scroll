# Coruscant V1 Asset Pack

All assets in this package were generated from `master-panorama-style-guide.png` and normalized for the generic scrolling-world engine.

Installed as the selectable `coruscant-city` world. Development URL: `?world=coruscant-city&seed=12345`.

## Inventory

- 1 opaque sky layer
- 2 transparent city parallax layers
- 1 continuous elevated transit-platform layer
- 8 distinct architecture silhouettes, including 1 landmark
- 2 civilian aerial vehicles, 1 maintenance drone, and 2 rare high-altitude fighters
- 5 stationary individual inhabitants, 1 rolling street-service robot, and 1 four-person armored patrol
- 3 grounded platform props

The package intentionally contains no world chunks, traffic schedules, event timing, or camera behavior. A world template composes those systems from these assets and recipes.
