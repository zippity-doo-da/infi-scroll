# Evention Typographic v1

A direct-authored monochrome asset pack. It does not depend on the world builder.

## Rules

- Black backdrop with unframed white outline letterforms.
- Inter-style display typography; DM Mono-style utility labels.
- `EVENTION` uses one large, low-positioned transparent word asset so native kerning is preserved.
- Product names remain exact and occupy independent far and middle parallax bands.
- Brand language, connected systems, operating process, and client outcomes occupy three additional depth bands.
- No streets, buildings, people, vehicles, weather, or baked motion.
- Every runtime band is a 1920 × 1080 seamless SVG.
